Moca identity companion

Run this locally to register the vault agent's key with your Moca account.

Why this page exists

@mocanetwork/airkit is browser-only — AirService drives HTMLIFrameElement and cannot be imported into the Node MCP server. Anything needing AIR Kit (login, agent keys, credential issuance) happens here; the server consumes only the results.

1 · Connect

not connected

2 · Register the agent key

Generate the keypair with npm run vault -- agent-key, then paste the public key. The private half stays in your macOS Keychain and is never sent anywhere. 

—

3 · Issue the storage credential (pending activation)

issueCredential returns cakPublicKey, which becomes the vault's key-encryption key. Until Credential Services are activated on your partner account this will fail — that is expected, and the vault runs on a local key until then.
